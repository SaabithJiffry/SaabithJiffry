## Featured Project: PresenterSync

[![Website Portal](https://img.shields.io/badge/Portal-saabithjiffry.github.io-10B981?style=for-the-badge)](https://saabithjiffry.github.io)
[![Latest Release](https://img.shields.io/github/v/release/SaabithJiffry/PresenterSync?style=for-the-badge&color=0EA5E9)](https://github.com/SaabithJiffry/PresenterSync/releases/latest)
[![Source Repo](https://img.shields.io/badge/GitHub-PresenterSync-111827?style=for-the-badge)](https://github.com/SaabithJiffry/PresenterSync)

**PresenterSync (v9.0.0)** bridges **OBS Studio**, **Zoom / Microsoft Teams / Google Meet**, **Microsoft PowerPoint**, **Windows Remotes**, **65"+ Android Smart Boards**, **Android Phones**, and a **Zero-Install Browser Web Remote** (iOS, iPadOS, macOS, Linux, Chromebook) into one synchronized presenter workflow:

* **Adaptive 4-Tier Host HUD + Independent Secondary Mic Pill:** CoreAudio peak meter, perimeter hold countdown safeguards (`Mic`, `Rec` click Start/Pause/Resume + hold Stop, `Studio` hold bar), drift-free OBS recording timer sync (`GetRecordStatus` anchor), calm seamless Scene marquee + right-click Live switch, strictly read-only Stream health pill, `1.25x` crisp indicator scaling across all 4 programs, and an independent primary-only Secondary Mic Pill.
* **Wireless Director Deck, Clicker Ergonomics & Presenter Timer:** Multi-device scene switching, Standby `"BRB"` curtains, synchronized countdowns, silent stage nudges, reorganized Tray menus, 1-click **Capture Keystroke** buttons beside all 43 shortcut fields, and Android Full-Screen OLED Podium Deck + 2×1 Home Widget.
* **Zero-Config Multi-Remote Sync & Failover:** Classroom UDP auto-discovery (`:4457`), LAN Host Bridge (`:4456`), zero-install HTML5 Web Remote (tap-to-mute, favicon branding, About modal, Clean Disconnect, pong watchdog auto-reconnect), Direct OBS `:4455` failover with `:4456` auto-repromotion, and AES-256-GCM WAN Relay.
* **Session Timeline & Guided Wizards:** Bounded 2,000-event timeline exporting to Video Editor CSV chapters, Markdown summaries, and YouTube timestamps, plus 1-tap SHA-256 verified self-updaters.
