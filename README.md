## Featured Project: PresenterSync

[![Website Portal](https://img.shields.io/badge/Portal-saabithjiffry.github.io-10B981?style=for-the-badge)](https://saabithjiffry.github.io)
[![Latest Release](https://img.shields.io/github/v/release/SaabithJiffry/PresenterSync?style=for-the-badge&color=0EA5E9)](https://github.com/SaabithJiffry/PresenterSync/releases/latest)
[![Source Repo](https://img.shields.io/badge/GitHub-PresenterSync-111827?style=for-the-badge)](https://github.com/SaabithJiffry/PresenterSync)

**PresenterSync** bridges **OBS Studio**, **Zoom / Microsoft Teams / Google Meet**, **Microsoft PowerPoint**, **65"+ Android Smart Boards**, and **Android Phones** into one synchronized presenter workflow:

* **Adaptive 4-Tier Host HUD + Independent Secondary Mic Pill:** CoreAudio peak meter, muted-voice alerts, recording timers, chat counters, scene switcher, live stream/VCam telemetry, plus an independent primary-only secondary mic pill.
* **Wireless Director Deck & Presenter Timer:** Multi-device scene switching, pause/split chapters, Standby `"BRB"` curtains, synchronized presenter countdowns, and silent stage nudges.
* **Zero-Config Multi-Remote Sync:** Classroom UDP auto-discovery (`:4457`), LAN & WAN Relay failover (`:4456`), DHCP IP-shift auto-follow, and Play Protect-friendly Smart Board gestures.
* **Session Timeline & Guided Wizards:** Bounded 2,000-event timeline exporting to Video Editor CSV chapters, Markdown summaries, and YouTube timestamps, plus 1-tap SHA-256 verified self-updaters.
